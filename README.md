# Webis Page

Webis landing page prototype built with plain HTML, CSS, and JavaScript.

## Open locally

Download or clone this repository, then open `index.html` directly in a browser.

No build step is required.

## Optional local preview server

If you want the same local preview URL used during development, run:

```bash
node server.js
```

Then open:

```text
http://127.0.0.1:4173/
```
